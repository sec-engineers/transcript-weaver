# Transcript Weaver HighLevel plugin

This is the official HighLevel output plugin for Transcript Weaver.
Install it only when a configured `trwout` profile needs to create or
update HighLevel contacts:

```bash
python3 -m pip install --user transcript-weaver-highlevel
```

The plugin and core TRW distributions are built from the same repository
and use the same project version. See the repository's configuration
reference for mapping, identity, and conservative update behavior.
